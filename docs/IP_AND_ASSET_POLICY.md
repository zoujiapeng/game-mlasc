# IP and asset policy

This project may reproduce broad genre conventions such as lap racing, drifting, boost pads, item pickups, chase cameras, and position-based balancing. It must not reproduce protected expression from a specific game.

Do not add:

- Nintendo or Mario names, characters, logos, icons, voices, music, sound effects, fonts, kart models, track geometry, item models, UI layouts, textures, screenshots, ripped data, or decompiled code.
- Near-identical recreations of recognizable tracks, characters, vehicles, item silhouettes, branding, or audiovisual sequences.
- Assets copied from websites, videos, or games without an explicit compatible license.
- “Free for personal use” assets in a project intended for commercial release.

Allowed sources:

- Original project work.
- CC0/public-domain assets.
- MIT/BSD/Apache licensed code, with notices where required.
- Commercial-use assets whose license permits inclusion in a compiled game.
- Commissioned assets with a written assignment or suitable license.

Every external asset must be documented in `THIRD_PARTY_NOTICES.md` before merge.
