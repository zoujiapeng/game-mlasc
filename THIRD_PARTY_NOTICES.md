# Third-party notices

The initial prototype contains no third-party art, music, sound effects, fonts, characters, logos, or level data. Runtime placeholder geometry, materials, particles, and audio are generated by project code using Unity primitives and APIs.

Unity Engine and Unity packages remain subject to Unity Technologies' own licenses and terms.

When a third-party asset is introduced, add an entry containing:

- Asset name and version
- Author/publisher
- Direct source page
- Exact license
- Files used or modified
- Required attribution text
- Date retrieved
